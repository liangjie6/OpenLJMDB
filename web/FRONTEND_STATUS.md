## 技术亮点 ⭐

1. **自动保存状态机** - 处理并发编辑、冲突检测、离线队列
2. **多标签页协调** - BroadcastChannel 同步状态，避免并发写入
3. **草稿隔离** - 按数据实例 ID 隔离，恢复后旧草稿不会自动提交
4. **任务轮询容错** - 数据库切换期间暂态错误不中断轮询
5. **类型安全** - 全栈 TypeScript，API 响应归一化
6. **无障碍** - 焦点管理、键盘操作、屏幕阅读器支持
